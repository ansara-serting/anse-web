# 🤝 Panduan Menyumbang ke ANSARA Serting Web (anse-web)

Terima kasih kerana berminat untuk menyumbang! Anda **tidak perlu tahu godam kod (coding)** untuk membantu membangunkan laman web ini.

---

## 📁 1. Menyumbang Kandungan (Berita / Trivia / Program)
Laman web ini menggunakan fail data ringkas berformat `.json` dalam folder `data/`.

* **Berita / Artikel Baru:** Kemas kini fail `data/berita.json`
* **Program / Banner Carousel:** Kemas kini fail `data/carousel.json`
* **Fakta / Trivia Alumni:** Kemas kini fail `data/trivia.json`

> **Langkah Mudah:**
> 1. Buka fail JSON berkaitan di GitHub.
> 2. Klik ikon pensel ✏️ (Edit).
> 3. Salin salah satu blok kandungan sedia ada, tampal di bawahnya, dan tukar teks mengikut maklumat baru.
> 4. Klik **Commit changes**.

---

## 📸 2. Menyumbang Gambar & Media
* Pastikan gambar jelas, berorientasikan mendatar (*landscape*), dan bersaiz tidak melebihi 2MB (digalakkan guna format `.webp` atau `.jpg`).
* Muat naik gambar ke folder `assets/`.
* Namakan fail imej secara spesifik (contoh: `iftar-2026-1.jpg`).

---

## 🐛 3. Melaporkan Masalah (Bug Report)
Jika anda menjumpai sebarang masalah (teks terpotong, butang tak boleh tekan, paparan senget di telefon):
1. Pergi ke tab **[Issues](../../issues)** di GitHub.
2. Klik butang **New Issue**.
3. Jelaskan masalah tersebut beserta:
   * Jenis peranti (contoh: *iPhone 13* / *Samsung Tab S8*)
   * Pelayar web (*Chrome*, *Safari*)
   * Tangkap layar (*screenshot*) masalah jika ada.

---

## 💡 4. Cadangan Penambahbaikan (Feature Request)
Ada idea menarik untuk mencantikkan laman web?
* Buka **Issue** baru dengan tajuk bermula `[CADANGAN]: Nama Idea Anda`.
* Ceritakan secara ringkas kenapa idea tersebut berguna untuk ahli alumni.
